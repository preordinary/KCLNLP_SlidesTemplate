Three properties of "right data"

  • Coverage — every reasoning skill seen at least 50× during training.
  • De-duplication at the document level, not just the n-gram level.
  • A held-out test split drawn from a different time period entirely.
  • Sampled at 1.3B params, then re-verified at 350M and 7B scale.
Spend extra time on point 3 — reviewers always ask about temporal contamination. Have the Sept-2024 cutoff date ready.

def curate(docs):
    docs = dedupe(docs, level="document")
    docs = filter_by_quality(docs, threshold="high")
    docs = balance_skills(docs, target="uniform")
    # 50× minimum exposure per reasoning skill
    docs = upsample_rare(docs, factor=50)
    return docs
